{%- comment -%} Sets the language variables used by the layout and includes: - site_langs: the site's languages, in menu order (en, es, la); - lang: this page's language, taken from the address (/es/… is Spanish, /la/… Latin, the rest English); this does not depend on the defaults in _config.yml, which `jekyll serve` does not reload; - t: this language's interface strings (_data/i18n.yml); - alt_urls / alt_found: for each language in site_langs, the address of this page in that language (matched by the `ref` front-matter key) and "y" if it exists; when it does not, alt_urls falls back to that language's home page. {%- endcomment -%} {%- assign site_langs = "en,es,la" | split: "," -%} {%- assign url_prefix = page.url | slice: 0, 4 -%} {%- assign lang = "en" -%} {%- if url_prefix == "/es/" -%}{%- assign lang = "es" -%}{%- elsif url_prefix == "/la/" -%}{%- assign lang = "la" -%}{%- endif -%} {%- assign t = site.data.i18n[lang] -%} {%- assign alt_urls = "" | split: "" -%} {%- assign alt_found = "" | split: "" -%} {%- if page.ref -%}{%- assign candidates = site.pages | where: "ref", page.ref -%}{%- else -%}{%- assign candidates = "" | split: "" -%}{%- endif -%} {%- for l in site_langs -%} {%- assign l_url = site.data.i18n[l].home -%} {%- assign l_found = "n" -%} {%- for candidate in candidates -%} {%- assign c_prefix = candidate.url | slice: 0, 4 -%} {%- assign c_lang = "en" -%} {%- if c_prefix == "/es/" -%}{%- assign c_lang = "es" -%}{%- elsif c_prefix == "/la/" -%}{%- assign c_lang = "la" -%}{%- endif -%} {%- if c_lang == l -%}{%- assign l_url = candidate.url -%}{%- assign l_found = "y" -%}{%- endif -%} {%- endfor -%} {%- assign alt_urls = alt_urls | push: l_url -%} {%- assign alt_found = alt_found | push: l_found -%} {%- endfor -%}
