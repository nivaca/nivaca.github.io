{%- comment -%} Sets the language variables used by the layout and includes: lang (this page's language), t (its interface strings), other_lang, and twin (the same page in the other language, matched by `ref`; nil if there is none). The language comes from the address: everything under /es/ is Spanish, the rest English. This does not depend on the defaults in _config.yml, which `jekyll serve` does not reload. {%- endcomment -%} {%- assign url_prefix = page.url | slice: 0, 4 -%} {%- if url_prefix == "/es/" -%} {%- assign lang = "es" -%}{%- assign other_lang = "en" -%} {%- else -%} {%- assign lang = "en" -%}{%- assign other_lang = "es" -%} {%- endif -%} {%- assign t = site.data.i18n[lang] -%} {%- assign twin = nil -%} {%- if page.ref -%} {%- assign candidates = site.pages | where: "ref", page.ref -%} {%- for candidate in candidates -%} {%- assign candidate_prefix = candidate.url | slice: 0, 4 -%} {%- if other_lang == "es" and candidate_prefix == "/es/" -%}{%- assign twin = candidate -%}{%- endif -%} {%- if other_lang == "en" and candidate_prefix != "/es/" -%}{%- assign twin = candidate -%}{%- endif -%} {%- endfor -%} {%- endif -%}
